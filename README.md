# Проект HomeworkOOP
## Описание:
Данный проект создан в рамках выполнения домашней работы по программе обучения "Python-разработчик".
## Установка и использование:
1. Откройте PyCharm
2. Клонируйте репозиторий:
```
git clone https://github.com/svetlana-rogova/HomeworkOOP
```
3. Установите зависимости через Poetry:
```
poetri install
```
4. Активируйте виртуальное окружение:
```
poetry shell
```
5. В модуле my_class.py реализованы классы Product и Category.
6. В модуле category_iteration добавлен класс для перебора товаров одной категории
7. В модуле new_class_Product добавлены новые продукты и реализована функция add, которая считает полную стоимость 
товаров на складе только если товары относятся к одному классу продуктов
8. В модуле class_order реализован класс "Заказы", который принимает ссылку на продукт и формирует вывод с названием и 
итоговой суммой.
9. В модуте base_product реализованы абстрактные классы
## Тестирование:
Все тесты лежат в директории tests/, имена модулей начинаются с test_.
В данной директроии реализованы тесты для каждого модуля из пакета src/.
Для запуска тестирования необходимо установить pytest:
```
poetry add --group dev pytest
```
Запустить тесты можно через команду pytest в терминале:
```
pytest
```
Чтобы проверить покрытие файла тестами нужно установить petest-cov в отдельную группу:
```
poetry add --group dev pytest-cov
```
Проверить покрытие можно через команду:
```
pytest --cov
```
